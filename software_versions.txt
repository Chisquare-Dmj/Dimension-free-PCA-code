Recorded software environment for the manuscript computations
=============================================================

The following versions were recorded on 2026-08-18 on the Linux computation
server used for the manuscript analyses. No package lockfile was created for the
original runs; this file records the software environment present when the public
reproducibility repository was finalized rather than claiming a bit-for-bit
frozen environment.

System
------
Operating system: Ubuntu 18.04.6 LTS
Architecture: x86_64-pc-linux-gnu
BLAS: OpenBLAS (/usr/lib/x86_64-linux-gnu/openblas/libblas.so.3)
LAPACK: OpenBLAS LAPACK 3.7.1

R
-
R version: 4.4.2 (2024-10-31)

Non-base R packages used by the real-data workflow:
  edfReader 1.2.1
  signal    1.8-1
  jsonlite  2.0.0

Note: `packageVersion("signal")` prints 1.8.1; the package DESCRIPTION records
the CRAN version as 1.8-1. The versions above were read from the R 4.4 user
library on the computation server.

Python
------
Python: 3.10.14
numpy:  1.23.5
pandas: 2.2.1

Dependency scope
----------------
- The simulation code uses base/recommended R functionality, including
  `parallel` for multicore execution on Unix-like systems.
- Rebuilding EEGMMIDB from the public EDF files uses `edfReader` and `signal`.
- CAPTURE-24 processing uses `jsonlite`; rebuilding the raw accelerometry cache
  also uses Python with `numpy` and `pandas` plus the system commands `curl`,
  `unzip`, `sha256sum`, and `python3`.
- The processed EEG and CAPTURE-24 caches included in the repository allow the
  manuscript analyses to be rerun without downloading and preprocessing the raw
  datasets.
